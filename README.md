# Vesta

An ultra-strict React + TypeScript workspace template for AI-assisted development.

Vesta enforces a **single correct pattern** for everything — file naming, state
management, data fetching, component structure, error handling. Tooling rejects
deviations at commit time so AI codegen and human contributors stay on rails.

## Status

Bootstrapping. The template is being built in layers; each layer ships as a
reviewed pull request. See the open PRs and the `CHANGELOG.md` (once layer 7
lands) for what's available.
